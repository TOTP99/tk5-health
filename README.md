🌟 TK5 Web Bluetooth 健康仪表盘 (TP制作🐈)
一个为 TK5 系列智能手环/戒指量身定制的网页端蓝牙仪表盘，利用 Web Bluetooth API 实现设备通信、健康追踪与本地数据提取。
🚀 核心功能
 * 无缝蓝牙连接：快速设备配对、服务与特征值发现（c1/c3 特征值）、自动时间校准及基础数据同步。
 * 实时健康监测：一键触发并监控实时健康测量：
   * ❤️ 心率 (data-mode="0")
   * 🩸 血压 (data-mode="1")
   * 💧 血氧 / SpO2 (data-mode="2")
   * ⚡ HRV (data-mode="10")
 * 全面历史同步：通过自定义二进制帧指令，拉取设备内部存储的历史数据块：
   * 睡眠历史 (0x0504) 与 步数历史 (0x0502)
   * 心率、血压、血氧、体温等历史日志
 * 数据管理与导出：
   * 一键将所有同步的健康记录打包导出为结构化的 JSON 文件，方便进行离线分析。
   * 带有十六进制原始日志输出的实时调试终端，支持一键复制。
 * 精致的暗色 UI/UX：
   * 采用响应式网格布局的沉浸式暗色主题。
   * 丰富的交互反馈，支持按钮发光视觉效果及 Web Audio API 动态合成音效。
   * 基于 Canvas 的历史指标趋势可视化。
🛠️ 协议与技术亮点
 * 通信架构：直接通过浏览器与硬件交互（Web Bluetooth），摆脱原生手机 App 的限制。
 * 帧协议解析：采用带 CRC16 校验的自定义二进制帧结构，确保命令下发可靠（例如状态码 0xfe 及数据键 0x010d）。
 * 本地持久化：将捕获的健康指标安全保存在浏览器本地存储（tk5Records）中，方便随时查询与备份。
🕹️ 快速开始
 * 在支持 Web Bluetooth 的浏览器（如桌面端或 Android 端的 Google Chrome / Microsoft Edge）中打开 index.html。
 * 点击 连接 (Connect) 按钮扫描并配对你的 TK5 设备。
 * 连接成功后，可通过界面查看实时统计、执行特定指标测量或同步历史数据。
 * 随时点击 导出JSON (Export JSON) 下载健康数据库，用于进行个性化分析。
